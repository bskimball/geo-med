# Typography

## Font Families

```css
--font-serif: 'Playfair Display', Georgia, serif;
--font-sans: 'Inter', system-ui, sans-serif;
```

## Headings (Playfair Display)

| Level | Size | Use |
|-------|------|-----|
| H1 | `clamp(3rem, 7vw, 5.5rem)` | Hero headlines |
| H2 | `clamp(2.25rem, 5vw, 3.75rem)` | Section titles |
| H3 | `clamp(1.75rem, 3.5vw, 2.5rem)` | Card titles, subsections |
| H4 | `clamp(1.375rem, 2.5vw, 1.875rem)` | Feature titles |

## Body Text (Inter)

| Type | Size |
|------|------|
| Base | `1.125rem` (18px) |
| Emphasized | `1.25rem` (20px) |
| Large | `1.5rem` (24px) |
| Line Height | `1.7` |

## Font Weights

Regular: 400 | Medium: 500 | Semibold: 600 | Bold: 700 | Extra Bold: 800
